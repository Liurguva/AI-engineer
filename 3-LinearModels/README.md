# Chapter 3 — Linear Models

- `3.linearmodel_solution.py`: closed-form linear regression.
- `3.linearmodel_optimize.py`: linear regression solved by numerical optimization.
- `3.linearmodel_logistic.py`: binary logistic regression from scratch.
- `3.linearmodel_kernel.py`: nonlinear regression with polynomial basis functions.
- `3.Lasso.py`: L1-regularized regression.
- `3.linearmodel_sklearn.py`: linear regression with scikit-learn.
- `3.linearmodel_logistic_sklearn.py`: multiclass logistic regression with scikit-learn.
