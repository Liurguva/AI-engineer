# Chapter 2 — AI Tools

- `2.numpy_basics.py`: arrays, vectorization, linear algebra, and broadcasting.
- `2.matplotlib_basics.py`: line, scatter, label, and layout fundamentals.
- `2.pandas_basics.py`: tabular data creation, filtering, grouping, and summary statistics.
- `Lab2-Tensorflow.py`: TensorFlow 2 tensors, automatic differentiation, and optimization.
- `Lab2-Keras.py`: a compact Keras classifier using the Iris dataset.
- `2.pytorch_basics.py`: PyTorch tensors, automatic differentiation, and optimization.

TensorFlow and PyTorch are optional dependencies.
