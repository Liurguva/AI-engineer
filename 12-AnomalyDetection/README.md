# Chapter 12 — Anomaly Detection

- `12.three_sigma.py`: three-sigma rule.
- `12.boxplot.py`: interquartile-range rule.
- `12.iForest.py`: isolation forest.
- `12.LOF.py`: local outlier factor.
- `12.autoencoder_DNN.py`: dense TensorFlow/Keras autoencoder.
- `12.autoencoder_CNN.py`: convolutional TensorFlow/Keras autoencoder.

The autoencoder scripts use the optional TensorFlow dependency and download MNIST on first run.
