# Chapter 9 — Ensemble Learning

- `9.bagging_voting.py`: bagging regression, bagging classification, and voting.
- `9.AdaBoost.py`: AdaBoost classification from scratch using decision stumps.
- `9.GradientBoost_GBDT.py`: gradient-boosted regression trees from scratch.
- `9.stacking_k_fold.py`: out-of-fold stacking.
