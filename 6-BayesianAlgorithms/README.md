# Chapter 6 — Bayesian Algorithms

- `6.Naive_Bayes.py`: categorical Naive Bayes from scratch.
- `6.Gaussian_Naive_Bayes.py`: Gaussian Naive Bayes from scratch.
- `6.Naive_Bayes_sklearn.py`: scikit-learn Naive Bayes comparison.
- `6.Bayesian_network_manual.py`: manually specified Bayesian network and inference with pgmpy.
- `6.Bayesian_network_autocoefficient.py`: learn network parameters for a fixed structure.
- `6.Bayesian_network_autostructure.py`: learn a discrete network structure from data.
- `6.Gaussian_process.py`: Gaussian-process regression from scratch and with scikit-learn.

The Bayesian-network scripts require the optional `pgmpy` package.
