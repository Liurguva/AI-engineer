# Chapter 15 — Policy-Based Reinforcement Learning

- `15.REINFORCE_bandit.py`: REINFORCE for a multi-armed bandit.
- `15.policy_gradient_gridworld.py`: policy-gradient learning in a small one-dimensional environment.
- `15.REINFORCE_cartpole.py`: neural REINFORCE for Gymnasium CartPole using PyTorch.

The CartPole script requires the optional Gymnasium dependency and PyTorch.
