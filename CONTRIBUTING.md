# Contributing

These examples are intended to remain short, readable, and closely connected to the notation and procedures used in *Artificial Intelligence for Engineers* by Zhen (Leo) Liu.

Before submitting a change:

1. Keep each example focused on one algorithm or learning objective.
2. Use English comments and descriptive variable names.
3. Avoid hidden data files, hard-coded absolute paths, and obsolete APIs.
4. Set random seeds when randomness affects the output.
5. Run `python tests/smoke_test.py` from the repository root.
6. Do not commit generated models, caches, virtual environments, or large downloaded datasets.

Please explain any mathematical or behavioral change in the pull request description.
