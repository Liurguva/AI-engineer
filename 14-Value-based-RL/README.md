# Chapter 14 — Value-Based Reinforcement Learning

- `14.q_learning.py`: tabular Q-learning in a one-dimensional treasure environment.
- `14.sarsa.py`: tabular on-policy SARSA in the same environment.
- `14.monte_carlo_control.py`: first-visit Monte Carlo control.
- `14.q_learning_gymnasium.py`: discretized Q-learning for Gymnasium CartPole.
- `14.sarsa_gymnasium.py`: discretized SARSA for Gymnasium CartPole.

The Gymnasium examples use the current `reset()` and `step()` return signatures and require the optional Gymnasium dependency.
