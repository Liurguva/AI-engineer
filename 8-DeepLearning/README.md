# Chapter 8 — Deep Learning

- `8.CNN_LeNet5.py`: NumPy implementation of convolution, average pooling, and a LeNet-style forward pass.
- `8.RNN.py`: simple recurrent neural network trained from scratch for sequence prediction.
- `8.RNN_LSTM.py`: LSTM cell equations implemented with NumPy.
- `Lab7-CNN-MNIST.py`: compact TensorFlow/Keras CNN for MNIST.
- `Lab7-LeNet-MNIST.py`: LeNet-5-style TensorFlow/Keras model.
- `Lab7-AlexNet-MNIST.py`: scaled AlexNet-style TensorFlow/Keras model.
- `8.pytorch_cnn_mnist.py`: compact PyTorch CNN for MNIST.
- `vanishing_gradient_demo.py`: numerical demonstration of vanishing and exploding gradients.

TensorFlow and PyTorch scripts use optional dependencies and may download MNIST on first run.
