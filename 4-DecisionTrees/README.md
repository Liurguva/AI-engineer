# Chapter 4 — Decision Trees

- `4.tree_leo_3.0.py`: categorical decision tree from scratch; choose `ID3`, `C4_5`, or `CART` in the script.
- `4.tree_sklearn.py`: CART classification with scikit-learn.
- `tree_plot_function.py`: lightweight plotting helper for nested-dictionary trees.
- `DT_watermelon_data.txt` and `DT_watermelon_feature.txt`: English version of the 17-sample categorical watermelon dataset.
